# PDS Mount Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write the weekly cleanup report to a Code Engine persistent data store mount instead of uploading it with the `ibmcloud cos` CLI.

**Architecture:** The job mounts PDS `ce-pds-9ef3` (path `/cleanup`) at `/mnt/reports`. The script writes the report there as a normal file and COS syncs it. A `deploy.sh` creates or updates the job with the mount.

**Tech Stack:** bash, jq, IBM Cloud CLI (`ibmcloud ce`), Docker.

**Spec:** `docs/superpowers/specs/2026-11-21-pds-mount-design.md`

## Global Constraints

- PDS name: `ce-pds-9ef3`; bucket `rst-usage-bucket-9yk456iwqnolk6p`; region `ca-tor`
- Mount: `/mnt/reports=ce-pds-9ef3:/cleanup`; script reads `REPORT_DIR`, default `/mnt/reports`
- Remove `COS_BUCKET_NAME`, `--region ca-tor` and the `cos` plugin install
- Lint with `shellcheck` before committing

## Review Focus

- `REPORT_DIR` missing: the script creates it
- `REPORT_DIR` not writable: non-zero exit with a clear message
- No tagged resources: no empty file left in `REPORT_DIR`, exit 0
- `ibmcloud resource search` fails: non-zero exit and no empty report
- Same-day re-run: overwrites that day's file

### Task 2: Dockerfile and deploy script

**Files:**
- Modify: `Dockerfile` (remove the `plugin install cos` step and its comment)
- Create: `deploy.sh`

**Interfaces:**
- Consumes: Task 1's `REPORT_DIR` default (`/mnt/reports`)

- [ ] **Step 1: Edit the Dockerfile.** Remove the `cos` plugin install lines.
- [ ] **Step 2: Create `deploy.sh`** (`set -euo pipefail`; takes `CE_PROJECT` and `IMAGE` from the environment). It selects the project and then creates the secret `cleanup-api-key` from `IBMCLOUD_API_KEY`, or updates it if it exists. Then it runs `ibmcloud ce job create` or `job update`, depending on whether the job `weekly-cleanup` already exists. Flags: `--image "$IMAGE" --mount-data-store /mnt/reports=ce-pds-9ef3:/cleanup --env-from-secret cleanup-api-key`.
- [ ] **Step 3: Verify.** Run `docker build .` (Expected: succeeds), `shellcheck deploy.sh` (Expected: no findings), and `bash -n deploy.sh`.
- [ ] **Step 4: Run the job in Code Engine** (`ibmcloud ce jobrun submit --job weekly-cleanup`) and check the logs. Expected: `Report generated successfully`. Then confirm `cleanup/cleanup_report_<date>.txt` exists in the bucket.
- [ ] **Step 5: Commit:**
```bash
git add Dockerfile deploy.sh
git commit -m "feat: add PDS mount deploy, drop cos plugin"
```
